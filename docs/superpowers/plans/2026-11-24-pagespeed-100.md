# PageSpeed 100 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PageSpeed 100 in every category (Agentic Browsing 3/3) on every page type, mobile and desktop, with the same look.

**Architecture:** An axe e2e suite is built first and drives the accessibility fixes. Then the weight goes: the icon font becomes inline SVG, text fonts shrink to two subsets, first-screen content stops starting invisible, pictures get sizes that match their boxes, and Plerdy and the map load on demand. Inlined CSS (approach B) is a conditional last step, decided by measurement.

**Tech Stack:** Astro 7, Tailwind 4, bun test, Playwright, `@axe-core/playwright` (new, dev), `@material-symbols/svg-400` (new, dev).

**Spec:** `docs/superpowers/specs/2026-11-24-pagespeed-100-design.md`

## Global Constraints

- Run commands from `application/frontend`. Run `bun run check:fix` before every commit.
- Commits: `type(scope): subject`, no co-author lines, no emojis. A hook that edits files fails the commit: re-stage and commit again.
- No visible redesign: same fonts, icons, layout. Only the gray gets darker.
- Content stays visible without JavaScript and with reduced motion.
- New strings go through `_()`; run `bun run i18n`, translate in `locales/ua.po`, run it again.
- No UI frameworks or `client:*` directives. Durations and easings only from the motion tokens.
- Test files: `*.test.ts` for bun, `*.e2e.ts` for Playwright (needs `bun run build` first).
- Nothing is pushed or deployed without the owner's go-ahead. Leave `application/ai-translator/` alone.

## Review Focus

1. An editor publishes an icon name the icon package does not have: the build passes and the `category` icon shows. (Task 3)
1. A very wide or very tall product photo in a card: still sharp after the smaller `sizes`. (Task 6)
1. Several interactions at once (scroll plus tap), or going back to a page: Plerdy loads once per page. (Task 7)
1. Contact page without JavaScript: a working map link instead of an empty box. (Task 7)
1. Reduced motion plus a window resize or rotation: the background pattern is redrawn, not blank. (Task 8)
