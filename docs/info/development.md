# Development

______________________________________________________________________

## Requirements

- **Node.js** ≥ 22.12
- **Bun** — package manager and test runner for the frontend
- **uv** — runs the Python infra scripts and tests
- **make** and **pre-commit**

```bash
make install-dev
make env
```

See [Environment](environment.md) for the variables.

______________________________________________________________________

## Frontend commands

Run from `application/frontend`.

| Command                | Description                                                           |
| ---------------------- | --------------------------------------------------------------------- |
| `bun run dev`          | Dev server at http://localhost:4321                                   |
| `bun run build`        | Production build into `dist/`                                         |
| `bun run preview`      | Preview the production build                                          |
| `bun test`             | Unit tests                                                            |
| `bun run check`        | Lint with Biome                                                       |
| `bun run check:fix`    | Biome lint + fix, then Prettier on `.astro`/`.tsx`/`.jsx`             |
| `bun run ci`           | Biome in CI mode (no fixes)                                           |
| `bun run i18n`         | Extract + compile translations in one step                            |
| `bun run i18n:extract` | Extract `_("…")` strings to `locales/messages.pot` and `locales/*.po` |
| `bun run i18n:init`    | Create a PO file for a new language                                   |
| `bun run i18n:compile` | Compile PO files into `src/i18n/ui.ts`                                |
| `bun run remark:check` | Lint content Markdown                                                 |
| `bun run remark:write` | Auto-fix content Markdown                                             |

## Infra commands

Run from the repository root.

```bash
make test-infra                                              # pytest for the infra scripts
uv run application/infra/scripts/check-images.py             # verify images in frontend/public
uv run application/infra/scripts/check-images.py --fix       # re-encode problem images in place
```

The image check fails on files whose extension does not match their real format, images larger than 1600 px on a side, and files over 300 KB.

## Translations

The site is bilingual. Write English text in components with `_("…")`, then:

```bash
bun run i18n         # update locales/*.po and regenerate src/i18n/ui.ts
```

Edit the `msgstr` values in `locales/ua.po`. `locales/messages.pot` and `src/i18n/ui.ts` are generated; do not edit them by hand. More detail is in [`application/frontend/CLAUDE.md`](../../application/frontend/CLAUDE.md).

## Content and CMS

Equipment, wiki articles and site data are Markdown/JSON under `application/frontend/src/content` and `src/data`, edited through Decap CMS.

- The CMS is at `/admin` on the dev server and on deployed sites. Sign in with GitHub; the account needs write access to the repository.
- Edits go through the editorial workflow (draft → review → publish). Commits are prefixed `[CMS] …`.
- The Decap config is generated by `/admin/config.yml` from `src/pages/admin/_config.template.yml`.
- Content Markdown is formatted by remark (the same way Decap writes it), not by mdformat.

The CMS needs `GITHUB_CLIENT_ID` and `GITHUB_CLIENT_SECRET`, see [Environment](environment.md#github-oauth-app-cms-login).

## Git hooks

`make install-dev` installs [pre-commit](../../.pre-commit-config.yaml) hooks for commit and push. On commit they:

- trim whitespace, fix end-of-file and line endings (LF), validate YAML/JSON;
- format Markdown with mdformat (content Markdown excluded);
- run i18n extract/compile, Biome with fix and Prettier on frontend changes;
- format content Markdown with remark;
- re-encode oversized or mislabeled images in `public/`;
- run Ruff on `application/backend/` if it exists.

On push they also run `biome ci`.

Hooks that modify files fail the commit. Re-stage the changes and commit again. Run them manually with `pre-commit run --all-files`.

## Commit messages

The repository ships a template in [`.gitmessage`](../../.gitmessage):

```
type(scope): subject
```

- Types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`, `ci`, `perf`.
- Scopes: `frontend`, `backend`, `root`, `docs`, `ci`, optionally nested (`frontend/ui`).
- Imperative mood, lowercase first letter, no trailing period, at most 72 characters.

Enable the template with `git config commit.template .gitmessage`.
