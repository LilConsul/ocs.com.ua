## Serialisation of Individual Folding Cartons

The Wipotec TQS-SP is a compact system for serialising individual folding cartons. The upper hold-down conveyor adjusts along three axes, so the system is easy to set up for different carton formats. Information is printed on demand on the pack flaps (front or back).

## Flexible Installation

The TQS-SP can be installed in a line with automated pack feeding or used as a mobile stand-alone unit with manual feeding.

## Single User Interface

Print data is sent directly to the printer and the camera. All system elements can be operated quickly and easily from a single user interface, without switching between programs.

## Main Components

* thermal inkjet printer for marking the pack on one side of the flap;
* 1 camera for reading and verifying the information on the flaps;
* reject device for rejecting packs with detected flap marking errors.
