# Translation glossary (EN to UA)

This file is the translation authority. The human owner has reviewed every row marked `ok`. A new
row starts as `draft` until the owner confirms it. The terms come from the bilingual equipment
pages of the website (`application/frontend/src/content/equipment/`) and from the technical terms
of the HC-A checkweigher datasheet.

Columns: `EN` is the source term, `UA` the required Ukrainian wording, `Avoid` lists forbidden
fragments separated by `;` (lint rejects any Ukrainian text that contains one, case-insensitively),
`Note` gives the source or the reason, `Status` is `draft` or `ok`. `Avoid` holds wording that
the website used and later replaced, or that the owner rejected.

## Style rules

- Numbers: decimal point, no thousands separator, as on the website (`0.01 г`, `7500 г`,
  `12.7 мм`). The source `4,000 g` becomes `4000 г`, `7,500` becomes `7500`. Never use a decimal
  comma.
- Units in Cyrillic, as on the website: `г`, `кг`, `мм`, `м/с`, `уп/хв` (for `ppm`), `шт/хв` (for
  `pcs/min`), `°С`. A space separates the number from the unit (`250 кг`).
- Model codes (`HC-A-2000-2`, `EC-2000-2`), certificate numbers (`DE-18-MI006-PTB001`), standards
  (`ISO 8573-1`), protocol and interface names (`OPC`, `RS232`), IP ratings (`IP54`, `IP69K`) and
  abbreviations such as `MID`, `PPS`, `TFT` stay verbatim.
- Translate the meaning, not word by word, and silently fix source typos (`lenght` is length,
  `rage` is range, `appli cation` is application).
- Never add or drop content: every heading, row, item, footnote and number in the English source
  has exactly one Ukrainian counterpart. The only exceptions are decisions of the human owner,
  such as the rules below.
- Names listed under `never_translate` in `sources.yaml` stay in Latin script, spelled as listed
  there. Do not repeat the list here.
- Reject: use the root `відбракув-` (`відбракування`, `відбракувальний пристрій`). The site
  also uses `вибракування` and `відбраковування`; check before marking terms `ok`.
- Machine: write `обладнання`, never `машина`.
- Noise level: write it short and keep the comparison, for example `< 70 дБ(A)` for
  "A-weighted emission sound pressure level under 70dB(A)".
- Interface languages: list Ukrainian (`українська`) and leave out Bosnian.
- Use the `UA` wording of the terms table; never use a fragment from its `Avoid` column.
